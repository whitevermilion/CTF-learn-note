# 脚本的写作

## Bash 脚本是终端命令的“集合”吗？

是的，完全正确。 Bash 脚本本质就是将一系列你平时在终端中手动输入的命令，按顺序写入一个文件，并赋予执行权限。Bash 会逐行解释执行这些命令，同时支持变量、条件判断、循环、函数等编程结构，从而实现自动化任务。

## 为什么 C 或 Java 一般不称为“脚本语言”，而 Python 可以？

🔹 关键区别：编译 vs 解释

    编译型语言（如 C、C++、Go、Rust）：
    源代码需要经过编译器一次性翻译成机器码，生成一个可执行文件（如 .exe 或二进制文件），之后运行该文件。这个过程叫“编译-链接-运行”，修改代码后必须重新编译才能生效。
    特点：执行速度快，适合系统级、性能敏感的任务。

    解释型语言（如 Bash、Python、Ruby、Perl）：
    源代码不需要提前编译，而是由解释器逐行读取并执行（或者先编译成字节码再解释）。修改代码后直接运行即可，无需中间步骤。
    特点：开发效率高，跨平台性好，适合快速编写自动化脚本、原型验证。

    混合型语言（如 Java、C#）：
    源代码先编译成中间码（字节码），再由虚拟机（JVM/CLR）解释执行或即时编译（JIT）。Java 通常被认为“编译型”，但运行机制有解释成分。不过通常不归类为“脚本语言”。

## Python 为什么常被用作脚本语言？

    它是解释执行的，写完后直接 python script.py 就能跑。

    语法简洁，有强大的标准库和第三方库，一行代码能完成文件操作、网络请求、数据处理等复杂任务。

    广泛用于自动化运维、爬虫、数据处理、测试等“胶水”场景。
